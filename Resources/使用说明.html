代码编辑器 · 使用说明

原生 AppKit 实现的轻量代码编辑器（Swift），由记事本升级而来：保留全部纯文本编辑与编码能力，新增语法高亮、行号栏与代码编辑辅助。启动快、打字跟手，10 MB 文件打开约 0.15 s。

代码编辑功能

  • 语法高亮：Swift / Objective-C / C / C++ / C# / Java / Kotlin / Python / JavaScript / TypeScript / Go / Rust / Ruby / PHP / Shell / PowerShell / SQL / Lua / HTML / XML / CSS / SCSS / JSON / YAML / TOML / Markdown / Dockerfile / Makefile 等 29 种语言，按扩展名自动识别，也可在状态栏或「代码 → 语言」手动切换
  • 行号栏：显示行号，当前行加亮；「代码 / 查看」菜单可开关
  • 当前行高亮 / 缩进参考线 / 括号匹配：光标所在行整行加亮，按缩进层级绘制参考线，光标旁的括号自动高亮另一半
  • 智能缩进：回车自动继承当前行缩进；在括号内回车自动多缩进一层并补全闭合括号；Tab / ⇧Tab 可对多行选区整体缩进
  • 自动配对：输入 ( [ { " ' 自动补全右半；选中文字后输入左括号直接包裹；输入右半自动跳过；退格成对删除
  • 主题：跟随系统 / Xcode 浅色 / Xcode 深色 / Monokai / Solarized 浅色 / GitHub 深色，全部偏好自动记忆

文本基础能力（继承自记事本）

  • 文件：新建 / 新窗口 / 打开 / 保存 / 另存为（可选编码与行尾）/ 页面设置 / 打印
  • 编辑：撤消 / 重做 / 剪切 / 复制 / 粘贴 / 删除 / 查找 / 替换 / 转到行 / 全选 / 插入时间日期
  • 编码：UTF-8、UTF-8 带 BOM、UTF-16 LE / BE（含无 BOM 自动识别）、ANSI（GB18030）
  • 行尾：Windows (CRLF)、Unix (LF)、Macintosh (CR)，自动识别、保存时按所选行尾写出
  • 状态栏：行列位置、语言、缩进、行尾、编码、缩放，均可点击切换
  • 其他：未保存三键提示、拖拽文件到窗口打开、多窗口级联、自动换行、字体对话框

设为默认编辑器

菜单「代码编辑器 → 设为默认文本编辑器…」可一键接管 txt / log / ini / csv / md / json 等文本格式的默认打开方式。源码格式（.swift / .py / .js 等）仅注册为「可打开」，不会抢占 Xcode、VS Code 等 IDE 的默认地位。

性能说明

  • 数据层为 UTF-8 字节级单遍实现，行号采用二分索引并在编辑时增量维护（定位 O(log n)）
  • 语法着色基于自研单遍扫描器，打字时只重绘改动的 token 区间，开销与改动量成正比
  • 超过 2 MB 的文件自动切换为纯文本模式以保证流畅（行号与编辑功能不受影响）
